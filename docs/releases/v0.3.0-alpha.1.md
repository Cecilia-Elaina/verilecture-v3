# VeriLecture `v0.3.0-alpha.1`

> Windows x64 pre-release

VeriLecture turns classroom audio into local, reviewable learning material. It
keeps the source recording and raw transcript available while making
corrections, vocabulary, and review points easier to revisit.

## Highlights

- Local-first audio import with support for WAV, MP3, and M4A.
- Hardware-aware onboarding with three ASR tiers:
  - `Fun-ASR-Nano-2512` for the CPU path.
  - `Qwen3-ASR-0.6B` for a lighter NVIDIA CUDA path.
  - `Qwen3-ASR-1.7B` for higher-quality NVIDIA CUDA transcription.
- Immutable raw transcripts with versioned calibration and edits.
- Optional course lexicons for domain-specific terminology.
- Consent-controlled text-model assistance for structured review points.
- Simplified Chinese and English interface support.
- Windows NSIS installer with verified FFmpeg resources and third-party notices.

## Important limitations

- This is an alpha release and is currently intended for Windows x64.
- The Qwen tiers require a separately hosted CUDA Runtime. Until that runtime
  is publicly available, choose `Fun-ASR-Nano-2512` for the CPU path.
- Model weights are downloaded on first use rather than bundled in the installer.
- Back up important recordings before installing a pre-release.

## Checksums
