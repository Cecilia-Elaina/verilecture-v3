# Third-party attribution

The product uses Tauri 2, React/Vite, Rust crates, Python runtime packages,
Qwen ASR/ForcedAligner, Fun-ASR-Nano, FSMN-VAD, the official Fun-ASR Windows
runtime and an approved FFmpeg build for non-WAV decoding. See
`THIRD_PARTY_NOTICES.md` for the distribution boundary and
`docs/MODEL_REGISTRY.md` for immutable model sources.

When assembling a release, copy every upstream LICENSE/NOTICE file into the
installer resources and include its attribution in the About/diagnostic view.
