# Stable error codes

Hardware/model: `HARDWARE_SCAN_FAILED`, `HARDWARE_PROFILE_INCOMPLETE`,
`CUDA_UNAVAILABLE`, `GPU_VRAM_INSUFFICIENT`, `SYSTEM_RAM_INSUFFICIENT`,
`DISK_SPACE_INSUFFICIENT`, `MODEL_NOT_INSTALLED`, `MODEL_DOWNLOAD_FAILED`,
`MODEL_DOWNLOAD_CANCELLED`, `MODEL_CHECKSUM_MISMATCH`, `MODEL_RUNTIME_MISSING`,
`MODEL_RUNTIME_SOURCE_UNAVAILABLE`, `MODEL_RUNTIME_REGISTRY_INVALID`,
`MODEL_RUNTIME_FAILED`, `MODEL_LOAD_FAILED`, `MODEL_SMOKE_TEST_FAILED`,
`MODEL_CORRUPTED`.

Audio/jobs: `AUDIO_FILE_NOT_FOUND`, `AUDIO_FORMAT_UNSUPPORTED`,
`AUDIO_DECODE_FAILED`, `AUDIO_RESAMPLE_FAILED`, `NO_SPEECH_DETECTED`,
`JOB_ALREADY_RUNNING`, `JOB_CANCELLED`, `JOB_RECOVERY_FAILED`.

Provider/content: `PROVIDER_NOT_CONFIGURED`, `PROVIDER_SECRET_MISSING`,
`PROVIDER_AUTH_FAILED`, `PROVIDER_RATE_LIMITED`, `PROVIDER_TIMEOUT`,
`PROVIDER_NETWORK_FAILED`, `PROVIDER_RESPONSE_INVALID`,
`PROVIDER_JSON_SCHEMA_FAILED`, `PROVIDER_CONSENT_REQUIRED`,
`SOURCE_DOCUMENT_UNSUPPORTED`, `SOURCE_DOCUMENT_TEXT_NOT_FOUND`,
`TEXTBOOK_UPLOAD_LIMIT_EXCEEDED`, `LEXICON_GENERATION_FAILED`,
`TRANSCRIPT_CALIBRATION_FAILED`, `EXAM_POINT_VALIDATION_FAILED`.

The UI maps stable codes to localized safe messages; raw provider responses are
never shown verbatim.
